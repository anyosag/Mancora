# Mancora branding

Mancora's mark is a breaking ocean wave rising out of the water inside a pale
circle. Máncora is a surf town on Peru's coast, which is where the name and
the wave come from.

## Files

| File | Use |
| --- | --- |
| `mancora-badge.svg` | Primary mark: the wave in its pale circle. |
| `mancora-mark.svg` | The wave and water without the circle, on a transparent ground. |
| `mancora-lockup.svg` | Badge plus the "Mancora" wordmark, for light grounds. |
| `mancora-lockup-dark.svg` | The same lockup with a light wordmark, for dark grounds. |
| `mancora-appicon-macos.svg` | 1024×1024 macOS icon master on Apple's grid (824 px body, 185 px corner radius). |
| `AppIcon.appiconset/` | macOS app icon PNGs, 16–1024 px, with `Contents.json`. |
| `Windows/mancora.ico` | Windows app icon, 16/24/32/48/256 px. |
| `Windows/*.scale-*.png` | MSIX tiles: Square44x44Logo, Square150x150Logo and StoreLogo at scale-100 and scale-200. |

The wordmark in the lockups is converted to outlines, so the SVGs need no fonts.

## Palette

| Name | Hex | Role |
| --- | --- | --- |
| Foam | `#F5FAFD` | Light ground |
| Shallows | `#C2EAFB` | Tints, badge ring |
| Lagoon | `#8ED2F2` | Crest highlight |
| Mancora Blue | `#4FAFE4` | Primary, deep water |
| Deep | `#0E4A6E` | Wordmark and text (9:1 on Foam) |
| Night | `#0B2A3F` | Dark ground |

- The wave gradient runs from `#A6DDF6` to `#4FAFE4`. The badge circle is `#E3F5FD`.
- Secondary text is `#2F6584` on light grounds and `#9CCBE6` on dark grounds.
- Text on Mancora Blue uses Night (6:1), not Deep.

## Type

The wordmark and headings use Outfit SemiBold (600) with −3% tracking.
Supporting copy uses Outfit Regular (400). Outfit is licensed under the SIL
Open Font License.

## Usage

- Clear space: keep a margin of one quarter of the badge's diameter on every
  side.
- Minimum size: 16 px for the badge, 120 px wide for the lockup.
- Don't recolor, stretch or outline the wave, and don't separate the wave from
  its water.

## Origin

All marks here are original work drawn for Mancora. They are not traced from
stock art, and they don't reuse any of Fiji's logos.
