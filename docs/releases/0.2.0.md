The second preview of **Mancora**, a native Swift port of Fiji (ImageJ) for scientific image analysis. Mancora now measures, filters and thresholds images, and runs ImageJ macros, giving ImageJ 1.54p's results. Anything it doesn't do natively yet, and Fiji's plugins from update sites, runs in ImageJ inside a Java helper. Throughout, results are checked against ImageJ itself.

## What's new in 0.2.0

**Images**

- TIFF reading adds:
  - Deflate compression, with both predictors
  - BigTIFF, and float16 and float64 data
  - 16-bit RGB(A)
  - ImageJ's own metadata (Info, slice labels, per-channel LUTs and ranges, ROIs, properties)
- Saving TIFFs as ImageJ does: ImageJ 1.54p reopens every file Mancora saves identically.
- Virtual stacks: a 2 GB stack opens in milliseconds and reads its planes on demand.

**Analysis, natively**

- Every ImageJ selection type, with ImageJ's exact masks, and `.roi` / `RoiSet.zip` files in both directions.
- Analyze ▸ Measure with Set Measurements, Analyze Particles, and the results table.
- Type conversions, Process ▸ Math and Image Calculator.
- Gaussian, rank, 3×3, convolution and binary filters.
- ImageJ's 17 automatic threshold methods, Convert to Mask and Z Project.

**Macros**

- ImageJ's macro language runs natively: the interpreter, the built-in functions, images, selections, results and the ROI Manager.
- `mancora --headless -macro file.ijm`, `-batch` and `-eval` work as in Fiji.
- A macro that needs something only ImageJ has runs there instead.

**Fiji plugins and update sites**

- A Java helper runs ImageJ and its plugins out of process. It restarts by itself if it dies.
- Fiji's update sites manage the helper's folder as Fiji's updater does:
  - the same checksums, statuses, dependencies and `db.xml.gz`, so Fiji can manage the folder too
  - every download verified before anything is installed
  - `mancora update-sites list | add | enable | disable | update`, and **Plugins ▸ Manage Update Sites…** in the Mac app
- Files in any format ImageJ or Bio-Formats reads open through the helper (`mancora bridge open`, and File ▸ Open in the Mac app).

**Apps**

- macOS viewer:
  - channel, slice and frame sliders, zoom and a pixel readout
  - Brightness & Contrast with ImageJ's Auto
  - Find Command, a Plugins menu, and the macro recorder
- Built-in updates in both viewers, and `mancora update`.

## Checked against ImageJ

- Every native command and a corpus of macros run in both Mancora and ImageJ 1.54p. Their images, logs, errors and results must match: integer images exactly, float results within 1e-9.
- The update-site code replays decisions recorded from Fiji's own updater (imagej-updater) and must reach the same ones.
- CI installs MorphoLibJ and Bio-Formats from Fiji's real update sites and runs them through the helper.

The Java helper needs Java 11 or later. `mancora bridge setup`, or the Mac app on first use, installs ImageJ 1.54p.
